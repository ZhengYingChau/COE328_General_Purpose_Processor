# General Purpose Processor
A General Purpose Processor, made for the final lab of COE328. Submitted December 1, 2025.

# Overview
A VHDL-based General-Purpose Processor (GPP), designed and implemented in Quartus II 13.0. The processor uses an ALU, control unit, FSM, and registers to perform 8-bit arithmetic and logic operations, with results displayed on 7-segment displays.

# Features

The GPP can take 2 binary inputs (A and B) and operate on them according to the instructions provided by the problem sets listed below.

Problem Set 1 (ALU_1): 
1. A + B
2. A - B
3. NOT A
4. A NAND B
5. A NOR B
6. A AND B
7. A OR B
8. A XOR B
9. A XNOR B

Problem Set 2 (ALU_2): 
1. |A - B|
2. Two’s complement of B
3. Swap 4 rightmost bits of A with B
4. Null
5. Decrement B by 5
6. Invert bit order of A
7. Shift B left 3 bits, insert 1s
8. Increment A by 3
9. NOT B

Problem Set 3 (ALU_3): 

ALU_3 runs through a chosen sequence of numbers and returns the parity of each digit.
